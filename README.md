# 🔐 Week 2 Cybersecurity Assessment Report

## Footprinting, Reconnaissance, and Network Scanning

**NetworkWalks Cybersecurity Program — Batch B083**

---

## 📄 Report Overview

This project documents authorized cybersecurity activities completed during Week 2 of the NetworkWalks Cybersecurity and Ethical Hacking internship.

The assessment covered:

- Web footprinting and reconnaissance
- DNS and domain-information gathering
- Web-technology identification
- HTTP-header inspection
- Web Application Firewall detection
- Local network discovery
- Host and MAC-address identification
- Network-topology mapping
- Risk analysis and security recommendations

All activities were conducted against authorized systems or personally owned equipment.

---

## 🎯 Assessment Objectives

The objectives of this project were to:

- Gather publicly available information about an authorized domain.
- Identify visible web technologies and infrastructure details.
- Review DNS records and HTTP response information.
- Detect indications of Web Application Firewall protection.
- Discover active hosts on an authorized local network.
- Document observations, risks, and recommendations.
- Practise professional cybersecurity reporting.
